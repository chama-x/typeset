## 3. Production CSS Implementation (`Dynamic Scale`, `Metric Trim`, `TrueGrade`)

```css
:root {
  /* Preset A: Architectural Precision Stack */
  --font-sans: 'Aspekta', 'Switzer', 'Plus Jakarta Sans', system-ui, sans-serif;
  --font-signature: 'Instrument Serif', 'Newsreader', Georgia, serif;
  --font-mono: 'Monaspace Neon', 'Commit Mono', ui-monospace, monospace;

  /* Harmonic Fluid Scale S(n, v) derived for V_min = 22.5rem (360px), V_max = 90rem (1440px) */
  --step--2: clamp(0.756rem, 0.738rem + 0.08vw, 0.810rem);    /* ~12px -> 13px | Micro & Badges */
  --step--1: clamp(0.870rem, 0.833rem + 0.16vw, 0.980rem);    /* ~14px -> 15.7px | Dense UI */
  --step-0:  clamp(1.000rem, 0.958rem + 0.19vw, 1.125rem);    /* 16px -> 18px | Base Reading */
  --step-1:  clamp(1.150rem, 1.053rem + 0.43vw, 1.440rem);    /* 18.4px -> 23px | Lead / H4 */
  --step-2:  clamp(1.323rem, 1.150rem + 0.77vw, 1.843rem);    /* 21px -> 29.5px | Section H3 */
  --step-3:  clamp(1.521rem, 1.242rem + 1.24vw, 2.359rem);    /* 24.3px -> 37.7px | Section H2 */
  --step-4:  clamp(2.010rem, 1.393rem + 2.74vw, 3.865rem);    /* 32px -> 61.8px | Display H1 */
  --step-5:  clamp(2.500rem, 1.500rem + 4.44vw, 5.500rem);    /* 40px -> 88px | 15% Hero */

  /* TrueGrade Polarity: P = 0 (Light Mode) -> GRAD 0; P = 1 (Dark Mode) -> GRAD -25 */
  --font-grade: 0;
}

@media (prefers-color-scheme: dark) {
  :root { --font-grade: -25; }
}
.dark, [data-theme="dark"] {
  --font-grade: -25;
}

/* 85% Core UI & Reading Surface */
body {
  font-family: var(--font-sans);
  font-size: var(--step-0);
  line-height: 1.58; /* Law 3: lambda(16, 65) */
  letter-spacing: 0em; /* Law 2: tau(16) = 0 */
  font-optical-sizing: auto;
  font-variation-settings: "GRAD" var(--font-grade);
  font-feature-settings: "cv05" 1, "cv08" 1, "ss01" 1, "kern" 1;
  -webkit-font-smoothing: antialiased;
  text-rendering: optimizeLegibility;
}

/* 15% Signature Hero with Logarithmic Tracking & Hyperbolic Leading */
.typeset-hero, h1 {
  font-family: var(--font-sans);
  font-size: var(--step-5);
  line-height: 1.06; /* Law 3: lambda(72, 20) */
  letter-spacing: -0.033em; /* Law 2: tau(72) = -0.022 * ln(72/16) */
  font-weight: 600;
  font-optical-sizing: auto;
  text-wrap: balance;
}

/* Law 5: Optical Voice Shift (Inline Italic Serif Normalized to Primary x-Height) */
.typeset-hero em, .voice-shift {
  font-family: var(--font-signature);
  font-style: italic;
  font-weight: 400;
  font-size-adjust: ex-height from-font;
  font-size: 1.06em; /* Fallback ratio alpha = x_1 / x_2 */
  letter-spacing: -0.012em;
  font-optical-sizing: auto;
}

/* W3C CSS Inline Layout Level 3: Exact Optical Box Trimming for Buttons, Badges & Cards */
button, .badge, .pill, .nav-item, .metric-value {
  text-box: trim-both cap alphabetic;
}

/* Micro Labels & Kicker Eyebrows (12px) */
.typeset-micro {
  font-size: var(--step--2);
  line-height: 1.35;
  letter-spacing: 0.018em; /* Law 2: tau(12) + micro boost */
  font-weight: 500;
  font-optical-sizing: auto;
}

/* Tabular Data & Live Metrics */
.typeset-tabular, table, time, .price, .metric {
  font-variant-numeric: tabular-nums slashed-zero;
  font-feature-settings: "tnum" 1, "zero" 1;

/* Substrate Code with Texture Healing */
code, pre, .typeset-code {

  font-size: 0.9em;

  font-size-adjust: ex-height from-font;

/* Long-Form Reading Measure */
```

## 4. Zero-CLS Metric Lock (`@font-face` & Next.js / Tailwind v4)

When self-hosting custom `.woff2` fonts, compute fallback overrides from the font's `OS/2` and `hhea` tables (`ascent / unitsPerEm`, `descent / unitsPerEm`, and $x$-height ratio $\alpha$):

```css
@font-face {
  font-family: 'CoreSans-MetricLock';
  src: local('BlinkMacSystemFont'), local('Segoe UI'), local('Helvetica Neue');
  size-adjust: 104.8%;
  ascent-override: 93%;
  descent-override: 23%;
  line-gap-override: 0%;
}
```

### Live DOM Physics Audit (Framework-Agnostic Browser Snippet)
To verify rendered typography in any running web app (via Playwright, DevTools, or Antigravity browser agent), evaluate this expression in the page context:

```javascript
(() => {
  const issues = [];
  document.querySelectorAll('h1, h2, p, table, button, code').forEach((el) => {
    const cs = getComputedStyle(el);
    const px = parseFloat(cs.fontSize);
    const ls = parseFloat(cs.letterSpacing) || 0;
    if (px < 18 && ls < -0.5) issues.push({ el: el.tagName, issue: 'Negative tracking on small text', px, ls });
    if (el.tagName === 'P' && el.getBoundingClientRect().width > px * 42) issues.push({ el: 'P', issue: 'Measure exceeds ~70ch' });
    if (el.tagName === 'TABLE' && !cs.fontVariantNumeric.includes('tabular-nums')) issues.push({ el: 'TABLE', issue: 'Missing tabular-nums' });
  });
  return { status: issues.length ? 'warn' : 'pass', issues };
})();
```
